# AGENTS.md

This project's agent instructions live in **[CLAUDE.md](CLAUDE.md)** — they apply to every coding agent, not only
Claude. Read it fully before starting.

Quick start for any agent with no chat history:
1. Read `CLAUDE.md` (stack, how to run, conventions, doc rules).
2. Read `docs/PROGRESS.md` (current phase, next steps, known issues).
3. Continue from the first unchecked phase in `docs/PHASES.md`. Never redo finished phases.
4. Record decisions in `docs/DECISIONS.md`; update `docs/PROGRESS.md` and the relevant doc with every change.

Docs: `docs/SPEC.md`, `docs/PHASES.md`, `docs/PROGRESS.md`, `docs/DECISIONS.md`, `docs/DATABASE.md`,
`docs/API.md`, `docs/SECURITY.md`, `docs/TEST_ACCOUNTS.md`, `docs/DEPLOYMENT.md`, `docs/MOBILE.md` (Phase 10+),
`docs/architecture.png`.
